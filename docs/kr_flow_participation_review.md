# 한국 수급 참여도 연구 — 검토 기록 (2026-10-02)

대상: `src/tradingbot/research/flow_participation.py` (커밋 `91ae155`, Codex Cloud 작성).

## 결론: 이 모듈의 출력은 신뢰하지 않는다. 고치지 않고 동결한다.

두 가지 이유가 독립적으로 작용한다.

1. **미국 시장에서 쓸 수 없다.** 투자자 유형별 매매대금은 한국거래소만 종목·일 단위로
   공시한다. 미국에는 대응 데이터가 없다(`config/us_etf_rotation.toml`의 주석이 이미
   적어둔 사실). 프로젝트 방향이 미국 개별주이므로 이 연구는 포팅 대상이 아니다.
2. **설계에 결함이 있다.** 아래 검토에서 확인됨.

코드는 테스트(전체 1270개 통과)와 함께 트리에 남긴다. 한국 트랙을 재개한다면 아래 결함을
먼저 고쳐야 한다.

## 방법

4개 독립 렌즈(선행정보 / 통계 타당성 / 데이터 열화 / 가설-구성 일치)가 각각 결함을
보고하고, 보고된 결함마다 **반증이 기본값인** 검증자가 코드를 직접 읽어 재현을 시도했다.
약 40건이 보고되었고, 완료된 검증 5건 중 3건이 기각되었다 — 검토가 과잉 주장을 실제로
걸러냈다는 뜻이다. 아래는 보고 내용이며 **검증 완료 여부를 구분해서 적는다.**

## 보고되었으나 검증이 끝나지 않은 결함 (가장 중대한 것)

이 둘은 연구 설계 자체를 겨냥한다. 검증이 완료되기 전에 이 모듈을 폐기 방향으로
정했으므로 확정하지 않았다. **미확정 상태로 읽어야 한다.**

- **critical** — `retail_participation = (개인매수+개인매도)/(2×거래대금)`은 비개인
  총회전의 산술적 여집합이다. 개인 비중이 낮다는 것은 기관·외국인 비중이 높다는 말과
  같으므로, 두 그룹은 "개인의 참여도"가 아니라 **기관 거래 강도**로 갈린다.
- **critical** — 직전 252거래일 중앙값을 기준으로 삼으면 개인 비중의 장기 추세가
  달력상의 시기 구분으로 바뀐다. 이때 원수익률은 개인 참여도가 아니라 **시대**를 잰다.

## 검증에서 기각된 보고

- docstring 인용이 다른 곳에서 가져온 것이라는 주장 — 오귀속이었고 README 설명은 코드와 일치
- 종목별 이벤트 간격 초기화가 교차 종목 중복을 만든다는 주장 — 메커니즘은 실재하나
  제기된 피해가 코드에서 확인되지 않았음
- 기관 순매수 크기가 요약에서 누락된다는 주장 — 해당 컬럼은 관측 단위 출력에 포함됨

## 선행정보는 문제가 아니다

`available_at`이 거래일 T의 수급을 T+1부터 사용 가능하게 설정하고(`panel.py:22-32`),
연구는 T+1 **시가**에 진입하므로 시점은 맞는다. 다만 연구 코드가 `available_at`을 읽지
않고 진입 규칙이 우연히 일치하는 구조라, 진입 시점을 바꾸면 조용히 깨진다. 그 보호
장치는 테스트로 고정되어 있지 않다.

## 수집기 결함 (수정함)

백필 시도에서 KRX가 점검 페이지를 서빙하고 있었다. 이때 `update_flows`는 모든 심볼이
실패했는데도 0을 반환하고 정상 종료했으며, 파이프라인은 이를 `STATUS_OK`로 기록한다.
`2ee343e`에서 전면 실패를 예외로 바꾸었다.

## 아직 남은 사실

- 저장된 수급 데이터(2015–2026)는 여전히 버전 1이며 새 컬럼이 없다. KRX 점검이 끝나기
  전에는 이 연구를 실행할 수 없고, 점검이 끝나도 위 결함 때문에 실행을 권하지 않는다.
- 이 연구는 결과 판정 규칙이 사전등록된 적이 없다. 그룹 2 × horizon 3 = 6개 셀을 판정
  규칙 없이 출력하며, 검토는 README의 읽는 절차가 순수한 귀무가설에서도 높은 비율로
  "발견"을 낸다고 지적했다.
